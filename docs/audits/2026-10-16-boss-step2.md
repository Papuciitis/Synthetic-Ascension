## First checkpoint: usable procedural courts

Both boss roles previously had semantic plazas without guaranteed fighting space: plaza cells mainly excluded decoration, while walls/half-cover and generic center landmarks could still intrude. Independently jittered arena roots also disagreed with the plaza center.

`BossArenaSpace` now defines a fixed chunk-center anchor and reserved S5 20×20-cell (1280 px) / S10 28×28-cell (1792 px) court. District generation protects the court before blockers and dressing are placed, paves the same region and connects it to the existing road reservations. Generic center landmarks are suppressed for these roles. The encounter builder uses the same deterministic center. No sealed doors or new mandatory encounter objectives are added.

Verification: the production-generator regression initially failed **257 passed / 471 failed**. The completed test passes **728/0**, covering 88 generated arena chunks across 40 spread seeds, repeat determinism, full court reservation, blockers, body-safe socket paths, perimeter, 16-direction rush/shock/beam lanes and dressing. The existing procedural reachability suite passes **3840 chunks, 2538 doors, 1728 rewards, zero failures**. Independent review found no additional spatial defect. [Evidence](evidence/2026-10-16-boss-step2/).

This guarantees the reserved court and connected access, not every point in the surrounding district. Current leash values still permit movement beyond the court; later committed attack-placement work must respect actual surrounding geometry. The player's camera follows the player, so an entire 680 px beam is not guaranteed to be visible from every position/orientation.
