## 4. Convention to adopt (no framework)

Observed today: `[ClassName] message` (28 files, dominant), `ClassName: message` (6 files), shouting tags, and no prefix (~14 files). The only once-guards in use are `_warned_missing_action` (HexBlink/ReflectShield) and `_printed_once` (ChunkGenImpl) — reuse them.

1. Prefix every line with the emitting script's class name in brackets, a verb phrase, then `key=value` pairs — `[EnemyDrops] no drop: spec=grunt prefixes=[acc_] fallback=false`; never abbreviations, milestone numbers, or ALL-CAPS tags.
2. `push_error` = invariant broken, data loss, or the run/screen cannot continue; `push_warning` = degraded but playable; `print` = developer trace only.
3. Every `print` sits behind a flag that defaults `false` (`@export var debug_prints := false` per effect, or `OS.is_debug_build()` for one-shot lifecycle lines); no unguarded `print` outside `tools/`.
4. Anything reachable from `_process`, a spawn/kill path, or a retry loop warns once per instance via a `_warned_<what>` bool, or aggregates into one line with a count.
5. Always carry the identifier that finds the asset (`spec.id`, `item_id`, `handle=`, `seed=`, `resource_path`, `scene_file_path`) and render engine errors with `error_string(err)`, never `str(err)`.
