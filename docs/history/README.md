# History

Patch-era records from the 0.23–0.25.x line (change manifests, the patch
manifest, procedural-generation and Segment 1 rebuild notes, the ground-texture
patch and the editor-recovery audit). Moved here from the repository root on
2026-08-29; nothing in the game or the tools reads them. The applied `.patch`
files, `PATCH_MANIFEST.sha256`, the `STATIC_VALIDATION_*.json` reports and
`RECOVERY_EDITOR_TMP_ARTIFACTS.zip` were deleted at the same time — git history
(`git log --all -- <name>`) keeps them.

Current direction: `docs/SYNTHETIC_ASCENSION_DIRECTION_AND_ROADMAP.md`.
