# City Development UI evidence

Native production Development screen and menu entry, captured with isolated test profiles. Arrival, selected augment and lower choices are shown at normal size and 150% UI scale. `capture-info.json` records the exact content/window sizes and panel bounds. The game uses KEEP aspect: a 640×480 window has 640×360 content. Two additional EXPAND captures are a separate layout stress check.

The illustrated values are several accumulated individual purchases in a test profile, not an automatic bundle. Current-attempt and prepared-next-attempt states deliberately differ. Binding Echo appears among the lower choices.

See `docs/audits/2026-10-16-city-development.md` for rules, verification and pacing limits.
