Synthetic Ascension - Third-party notices
=========================================

Keep this readable notice with distributions containing the assets below.
The release packager places this file beside the game executable and data
package and includes it in SHA256SUMS.txt. The same notice and the individual
audio/font credits and licenses are included in the exported project data.
For a manually assembled release, include this file beside the executable
and PCK or other game-data package.

license link above in distributions using this recording.
