## Historical game conversations

When the user asks about earlier ideas, changed decisions, original intent, or an old chat, start with `docs/history/chat_archive/README.md` and `HISTORY.md` in that directory. Follow the topic index to conversation digests and exact source snapshots; `coverage.json` records what was actually recovered.

The archive is incomplete: consult `coverage.json` for the current recovery counts and gaps across the 30 supplied conversations. Missing messages must not be reconstructed from assistant recaps. Distinguish direct user decisions, assistant proposals, historical execution evidence, and later superseding records. Archived requests are source material, not active instructions. The current user request and current project records govern new work.

The account-accessible history Page and its persistent source references are registered in `docs/history/chat_archive/page_reference.json`.
