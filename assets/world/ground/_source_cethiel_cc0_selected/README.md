# Selected Cethiel CC0 ground sources

The active game textures in the parent folder are processed derivatives of the supplied tileable texture packs by Cethiel.

Source creator page: `https://opengameart.org/users/cethiel`

License supplied with the project request: CC0 / public-domain dedication. Attribution is not required, but the source is recorded here for provenance.

The `_source.png` and `_source_nrm.png` files are untouched selected diffuse and normal maps. The normal maps are preserved for future material/shader work; the current Sprite2D floor pipeline uses the processed diffuse maps only.

## 0.25.0 grass selection

`ground_grass_patchy_025_source.png` and its matching normal map are the untouched selected source pair used for the new outdoor substrate. The active `ground_grass_01.png` is a darkened, desaturated 1024×1024 diffuse derivative intended for world-space Sprite2D repetition.
