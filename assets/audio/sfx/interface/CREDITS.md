# Interface feedback

Source: [Kenney UI Audio](https://kenney.nl/assets/ui-audio), version 1.0 (2012), retrieved 14 October 2026.

License: Creative Commons CC0 1.0. The archive's original License.txt is included beside these files.

Recordings are decoded to 16-bit PCM WAV from the official Ogg archive. No cuts, filtering or other sound edits are applied. WAV avoids a reproducible Godot 4.7.1 crash while importing this archive's Ogg files.

| Local file | Original file | Purpose |
| --- | --- | --- |
| hover.wav | Audio/rollover2.ogg | Short navigation tick, −18 dB |
| click.wav | Audio/click1.ogg | Button and selection, −14 dB |
| toggle.wav | Audio/switch12.ogg | Toggle, option and tab, −16 dB |

The existing interface Back and Error recordings remain in the manifest. All five use the Interface (UI) bus and respect its volume and mute settings. No pitch randomization is applied to these menu sounds.
